# Установка OpenWrt на Xiaomi AX3000T RD23

[Скачать инструкцию в формате Word](docs/Инструкция_OpenWrt_Xiaomi_AX3000T_RD23.docx)

В репозитории намеренно нет образов прошивки и резервных копий NAND. Загружайте OpenWrt только с официального сайта, а персональную резервную копию храните локально.

Пошаговая инструкция для обычного пользователя Windows 11  
Актуальность: 9 ноября 2026 года  
Целевая модель: **Xiaomi AX3000T RD23, MediaTek MT7981, 128 МБ NAND, 256 МБ RAM**

> **Важно:** эта инструкция предназначена только для RD23 и совместимого RD03 на MediaTek. Она **не подходит** для RD03v2 на Qualcomm IPQ5018. Прошивка от другой аппаратной версии может вывести роутер из строя.

## Что получится в результате

- OpenWrt 25.12.6 вместо заводской прошивки Xiaomi;
- веб-интерфейс LuCI по адресу `http://192.168.1.1`;
- подключение к провайдеру по PPPoE;
- отдельные сети Wi‑Fi 2,4 и 5 ГГц;
- возможность устанавливать пакеты, настраивать zapret2, VPN и другие функции.

## Главные правила безопасности

1. Выполняйте установку **только по Ethernet-кабелю**. Не прошивайте через Wi‑Fi.
2. Заранее скачайте все файлы: во время установки Интернет пропадёт.
3. Не отключайте питание во время записи прошивки и не нажимайте Reset.
4. Не используйте файлы с `ubootmod` в названии. Эта инструкция сохраняет штатный загрузчик Xiaomi.
5. Не используйте прошивку для RD03v2, WR30U, AX3000NE или другого роутера.
6. Не продолжайте, если XMiR-Patcher показывает другую модель, ошибки чтения NAND или не создаёт резервную копию.
7. Резервная копия NAND уникальна: она содержит калибровочные данные Wi‑Fi и MAC-адреса. Не публикуйте её и не используйте копию от другого роутера.

## Что потребуется

- Xiaomi AX3000T с маркировкой **RD23** на наклейке;
- компьютер или ноутбук с Windows 11 и Ethernet-портом/USB–Ethernet-адаптером;
- исправный сетевой кабель;
- стабильное питание;
- пароль от заводского веб-интерфейса Xiaomi;
- параметры подключения к провайдеру: PPPoE, DHCP/IPoE, статический IP или другой используемый способ;
- 1–2 ГБ свободного места для инструментов и резервных копий.

До начала запишите или сфотографируйте:

- тип подключения к провайдеру и все его параметры;
- PPPoE-логин и пароль, если используется PPPoE;
- статический IP, маску, шлюз и DNS, если они выданы провайдером;
- номер VLAN, если он используется;
- исходный WAN MAC, если у провайдера есть привязка по MAC;
- имя и пароль домашнего Wi‑Fi;
- адреса серверов, сертификаты или другие параметры, если используется особая схема авторизации.

Не вставляйте эти данные в форумы, чаты и скриншоты.

## 1. Проверка аппаратной версии

Посмотрите наклейку снизу и коробку.

Продолжать можно, если указано:

```text
Model: RD23
```

Официальная страница OpenWrt указывает, что RD23 и первоначальный RD03 используют MediaTek MT7981 и совместимы. Новая модель RD03v2 построена на Qualcomm и требует других образов.

**Немедленно остановитесь**, если:

- указано `RD03v2`;
- на коробке SKU `DVB4510CN`, а штрихкод заканчивается на `706330`;
- XMiR-Patcher определяет Qualcomm/IPQ5018;
- модель не удаётся определить однозначно.

## 2. Скачивание необходимых файлов

### 2.1. XMiR-Patcher

Скачайте XMiR-Patcher только из основного репозитория:

<https://github.com/openwrt-xiaomi/xmir-patcher>

Нажмите **Code → Download ZIP**, распакуйте архив в короткий путь без кириллицы, например:

```text
C:\xmir-patcher
```

Не скачивайте перепакованные архивы с форумов и файловых обменников. Не отключайте антивирус ради запуска неизвестной копии инструмента.

### 2.2. Официальные образы OpenWrt 25.12.6

Нужны ровно два файла из официального каталога `mediatek/filogic`:

1. Первичная загрузка:

```text
openwrt-25.12.6-mediatek-filogic-xiaomi_mi-router-ax3000t-initramfs-factory.ubi
```

2. Постоянная установка:

```text
openwrt-25.12.6-mediatek-filogic-xiaomi_mi-router-ax3000t-squashfs-sysupgrade.bin
```

Каталог загрузки:

<https://downloads.openwrt.org/releases/25.12.6/targets/mediatek/filogic/>

Не выбирайте файлы, содержащие `ubootmod`, `wr30u`, `rd03v2`, `recovery.itb`, `preloader` или `bl31`.

### 2.3. Проверка SHA-256

Откройте PowerShell в папке с файлами и выполните:

```powershell
Get-FileHash .\openwrt-25.12.6-mediatek-filogic-xiaomi_mi-router-ax3000t-initramfs-factory.ubi -Algorithm SHA256
Get-FileHash .\openwrt-25.12.6-mediatek-filogic-xiaomi_mi-router-ax3000t-squashfs-sysupgrade.bin -Algorithm SHA256
```

Для официальной сборки 25.12.6 должны получиться:

```text
initramfs-factory.ubi:
4ec4eb9d5d9e03cf437c0942d9389343e3b70536fbe3a84827db04fcb8482c2f

squashfs-sysupgrade.bin:
286dbbaf16588c22daeaf6dbc8ca02573a1c30fbeb8592e3ba58b865c8726043
```

Если хотя бы одна сумма отличается, удалите файл и скачайте заново. Не прошивайте его.

## 3. Подготовка компьютера и роутера

1. Отключите на компьютере Hiddify, VPN, прокси и сторонние сетевые фильтры.
2. Временно отключите Wi‑Fi компьютера, оставив только Ethernet.
3. Заранее скачайте эту инструкцию, XMiR-Patcher и оба образа OpenWrt.
4. Отсоедините WAN-кабель провайдера от Xiaomi.
5. Соедините компьютер кабелем с одним из средних Ethernet-портов Xiaomi.
6. В свойствах IPv4 сетевого адаптера оставьте автоматическое получение IP и DNS.
7. Убедитесь, что заводской интерфейс Xiaomi открывается, обычно по адресу:

```text
http://192.168.31.1
```

## 4. Подключение XMiR-Patcher

1. Откройте распакованную папку XMiR-Patcher.
2. Запустите `run.bat` обычным пользователем.
3. В меню проверьте адрес роутера. Если требуется, выберите:

```text
1 - Set IP-address
```

и укажите:

```text
192.168.31.1
```

4. Выберите:

```text
2 - Connect to device (install exploit)
```

5. Введите пароль от заводского веб-интерфейса Xiaomi только в локальном окне XMiR-Patcher.
6. Дождитесь успешного подключения. Не продолжайте при сообщениях о неподдерживаемой прошивке или невозможности установить соединение.

Эксплойт зависит от версии заводской прошивки. Если пункт 2 завершается ошибкой, не перебирайте случайные команды и не устанавливайте прошивки от другой модели — сначала сверяйтесь с актуальной страницей устройства OpenWrt.

## 5. Проверка информации о роутере

В XMiR-Patcher выберите:

```text
3 - Read full device info
```

Проверьте:

- модель определяется как `RD23` или совместимый AX3000T;
- архитектура `arm64/aarch64`;
- SoC относится к MediaTek MT7981;
- NAND-разметка успешно прочитана;
- инструмент не сообщает о несовместимости.

Если модель или разметка отличаются — остановитесь.

## 6. Обязательная полная резервная копия

Выберите:

```text
4 - Create full backup
```

Дождитесь сообщения `Completed!`. Процесс может занять несколько минут.

XMiR-Patcher сохраняет разделы в папку:

```text
xmir-patcher\backups\
```

Проверьте, что там появились файлы вроде:

```text
mtd...bin
```

Скопируйте всю папку `backups` минимум в два места, например:

- на основной диск компьютера;
- на отдельную флешку или внешний диск.

Не продолжайте установку, если резервная копия завершилась с ошибками или файлы имеют нулевой размер.

## 7. Первая стадия: запуск OpenWrt initramfs

1. Очистите папку:

```text
xmir-patcher\firmware\
```

2. Поместите в неё **только** файл:

```text
openwrt-25.12.6-mediatek-filogic-xiaomi_mi-router-ax3000t-initramfs-factory.ubi
```

3. Ещё раз убедитесь, что в названии нет `ubootmod`.
4. В XMiR-Patcher выберите:

```text
7 - Install firmware (from directory "firmware")
```

5. Инструмент должен распознать образ как совместимый с AX3000T. Прекратите операцию, если он сообщает о несовместимости модели.
6. Подтвердите запись только после проверки имени файла и модели.
7. Не отключайте питание. После завершения дождитесь перезагрузки роутера.

Первый образ запускает временную систему OpenWrt из initramfs. Это ещё не окончательная установка.

## 8. Подключение к временной OpenWrt

1. Подождите 3–5 минут.
2. Убедитесь, что кабель подключён к среднему LAN-порту.
3. Переподключите Ethernet или выполните в PowerShell:

```powershell
ipconfig /release
ipconfig /renew
```

4. Компьютер должен получить адрес `192.168.1.x`.
5. Проверьте:

```powershell
ping 192.168.1.1
```

6. Подключитесь по SSH:

```powershell
ssh root@192.168.1.1
```

При первом подключении введите `yes`. В initramfs пароль root обычно ещё не установлен.

## 9. Вторая стадия: постоянная установка

Откройте ещё одно окно PowerShell в папке с `sysupgrade.bin` и загрузите файл в оперативную память роутера:

```powershell
scp -O .\openwrt-25.12.6-mediatek-filogic-xiaomi_mi-router-ax3000t-squashfs-sysupgrade.bin root@192.168.1.1:/tmp/
```

Ключ `-O` нужен новым версиям OpenSSH в Windows, потому что стандартная OpenWrt обычно не содержит SFTP-сервер.

В SSH проверьте контрольную сумму загруженного файла:

```sh
sha256sum /tmp/openwrt-25.12.6-mediatek-filogic-xiaomi_mi-router-ax3000t-squashfs-sysupgrade.bin
```

Она должна совпасть:

```text
286dbbaf16588c22daeaf6dbc8ca02573a1c30fbeb8592e3ba58b865c8726043
```

Затем выполните окончательную установку:

```sh
sysupgrade -n /tmp/openwrt-25.12.6-mediatek-filogic-xiaomi_mi-router-ax3000t-squashfs-sysupgrade.bin
```

Параметр `-n` нужен для чистой первой установки: настройки временной initramfs не переносятся.

После запуска команды:

- SSH отключится;
- индикатор может менять цвет или мигать;
- роутер автоматически перезагрузится;
- ничего не нажимайте и не отключайте питание минимум 10 минут.

## 10. Первый вход в постоянную OpenWrt

1. Переподключите Ethernet.
2. Откройте:

```text
http://192.168.1.1
```

3. Имя пользователя:

```text
root
```

4. Если пароль ещё не задан, оставьте поле пустым и сразу установите надёжный пароль:

```text
Система → Администрирование → Пароль роутера
```

5. Установите часовой пояс:

```text
Система → Система → Часовой пояс
```

6. Проверьте модель и версию на странице «Статус → Обзор».

Дополнительная проверка по SSH:

```sh
ubus call system board
```

Ожидаемые признаки:

```text
target: mediatek/filogic
architecture: aarch64_cortex-a53
model/board: Xiaomi Mi Router AX3000T
```

## 11. Настройка подключения к провайдеру

Не подключайте WAN к случайному порту до проверки назначения интерфейсов в LuCI.

Способ подключения нужно узнать **до прошивки**: посмотреть в заводском интерфейсе Xiaomi, договоре или инструкции провайдера. Не выбирайте PPPoE только потому, что он часто используется. У разных провайдеров применяются разные схемы, а иногда несколько технологий одновременно.

Откройте:

```text
Сеть → Интерфейсы → WAN → Изменить
```

и выберите вариант, соответствующий данным провайдера.

### Вариант A: PPPoE

1. Выберите протокол:

```text
PPPoE
```

2. Введите логин и пароль, выданные провайдером.
3. Для IPv6 оставьте автоматическое согласование, если провайдер поддерживает IPv6.
4. Не меняйте MTU без прямого требования провайдера. Для PPPoE OpenWrt обычно устанавливает подходящее значение автоматически.

Рабочее PPPoE-соединение обычно создаёт логический интерфейс `pppoe-wan`.

### Вариант B: DHCP / IPoE / динамический IP

Если провайдер не выдавал логин и пароль, а заводской роутер получал Интернет автоматически, обычно нужен:

```text
DHCP-клиент
```

Логин и пароль в этом режиме не вводятся. Если адрес не получается, возможна привязка по MAC, необходимость VLAN или регистрация нового роутера у провайдера.

### Вариант C: статический IP

Выберите:

```text
Статический адрес
```

Введите без изменений данные провайдера:

- IPv4-адрес;
- маску сети или длину префикса;
- шлюз;
- DNS-серверы;
- при необходимости параметры IPv6.

Не придумывайте эти значения самостоятельно. Ошибка в маске или шлюзе полностью отключит Интернет.

### Если используется VLAN

VLAN — это не отдельный способ авторизации, а дополнительная маркировка трафика. Провайдер может использовать:

- PPPoE поверх VLAN;
- DHCP/IPoE поверх VLAN;
- отдельные VLAN для Интернета, IPTV и телефонии.

Понадобится точный VLAN ID от провайдера. В OpenWrt сначала создаётся устройство VLAN 802.1Q на физическом WAN, а затем оно назначается интерфейсу WAN с нужным протоколом.

Не копируйте VLAN ID из чужой инструкции: даже у одного провайдера он может отличаться по региону и типу услуги. Если одновременно используются Интернет и IPTV, не настраивайте их методом проб и ошибок — запросите у провайдера точную схему портов и VLAN.

### Если есть привязка по MAC-адресу

Признаки привязки:

- старый роутер получает Интернет, а новый — нет;
- DHCP не выдаёт адрес после замены устройства;
- провайдер просит зарегистрировать оборудование.

Варианты решения:

1. Сообщить провайдеру новый WAN MAC OpenWrt.
2. Временно скопировать WAN MAC заводского роутера в расширенных настройках интерфейса WAN.
3. Подождать истечения старой DHCP-аренды, если это предусмотрено сетью провайдера.

Не меняйте MAC без необходимости и предварительно запишите исходное значение.

### L2TP, PPTP или VPN-соединение провайдера

Некоторые провайдеры используют L2TP или устаревший PPTP поверх предварительно полученного IP-адреса. Для такой схемы могут понадобиться дополнительные пакеты OpenWrt и адрес VPN-сервера провайдера.

До прошивки сохраните:

- тип протокола;
- адрес сервера;
- логин и пароль;
- способ получения базового IP;
- маршруты и DNS, указанные провайдером.

PPTP считается устаревшим и небезопасным, но менять схему доступа самостоятельно нельзя: сначала уточните у провайдера доступность современного варианта.

### 802.1X, сертификат или особая авторизация

Если провайдер использует 802.1X, сертификат, EAP, специальное приложение или уникальный идентификатор линии, стандартной настройки PPPoE/DHCP недостаточно. Понадобятся дополнительные пакеты и точные параметры от провайдера.

Не прошивайте основной и единственный роутер, пока не подтверждено, что такая схема поддерживается в OpenWrt и все сертификаты/ключи сохранены.

### Веб-авторизация

В некоторых сетях WAN получает адрес по DHCP, а затем требуется открыть страницу провайдера и подтвердить доступ. В этом случае сначала настраивается DHCP-клиент, затем выполняется авторизация через браузер. Уточните, привязывается ли сессия к MAC-адресу.

### Сохранение и проверка

После выбора правильной схемы:

1. Не меняйте устройство WAN, VLAN и MAC, если провайдер этого не требует.
2. Нажмите «Сохранить», затем «Сохранить и применить».
3. Подключите кабель провайдера в назначенный WAN-порт.
4. Откройте `Статус → Обзор` и проверьте наличие WAN-адреса и маршрута по умолчанию.
5. Сначала проверьте доступ по IP, затем DNS.

Команды диагностики:

```sh
ifstatus wan
ip route show default
ping -c 3 1.1.1.1
nslookup openwrt.org
```

Если WAN не работает, перепроверьте тип подключения, учётные данные, VLAN, MAC-привязку и физический порт. Не меняйте сразу несколько параметров: иначе будет невозможно понять причину.

## 12. Настройка Wi‑Fi

В OpenWrt радиосети после первой установки могут быть выключены.

1. Откройте:

```text
Сеть → Беспроводная сеть
```

2. Для диапазона 2,4 ГГц нажмите «Изменить»:
   - задайте имя сети;
   - выберите страну;
   - включите WPA2/WPA3 Personal либо WPA2 Personal для старых устройств;
   - задайте длинный пароль;
   - включите сеть.
3. Повторите для 5 ГГц.
4. Сначала используйте автоматический или заведомо разрешённый канал. DFS-каналы 5 ГГц могут запускаться с задержкой из-за проверки радара.
5. Нажмите «Сохранить и применить».

Проверьте подключение телефона отдельно к 2,4 и 5 ГГц.

## 13. Финальная проверка

Проверьте по порядку:

- LuCI открывается по Ethernet;
- SSH работает;
- PPPoE подключено;
- обычный сайт открывается;
- IPv4 работает;
- IPv6 работает, если предоставляется провайдером;
- Wi‑Fi 2,4 ГГц работает;
- Wi‑Fi 5 ГГц работает;
- после перезагрузки настройки сохраняются.

Команды диагностики:

```sh
ip route show default
ip -6 route show default
ping -c 3 1.1.1.1
nslookup openwrt.org
```

## 14. Резервная копия уже настроенной OpenWrt

После успешной настройки создайте отдельную копию конфигурации:

```text
Система → Резервная копия / Обновление прошивки → Создать архив
```

Храните отдельно:

1. исходную полную NAND-копию XMiR-Patcher;
2. архив конфигурации OpenWrt;
3. записанные параметры PPPoE;
4. точное имя установленного образа и его SHA-256.

Архив OpenWrt может содержать PPPoE-пароль, ключи Wi‑Fi и другие секреты. Не публикуйте его.

## 15. Как правильно обновлять OpenWrt в будущем

Для обновления уже установленной OpenWrt используйте только файл вида:

```text
...xiaomi_mi-router-ax3000t-squashfs-sysupgrade.bin
```

Не используйте `factory.ubi`, `ubootmod`, `preloader` или `bl31` для обычного обновления.

Перед обновлением:

1. Проверьте `ubus call system board`.
2. Создайте свежую резервную копию.
3. Скачайте образ строго для `xiaomi_mi-router-ax3000t` и `mediatek/filogic`.
4. Проверьте SHA-256.
5. При переходе между крупными версиями проверьте совместимость конфигурации и пакетов.

Для новичка предпочтительно обновление через:

```text
Система → Резервная копия / Обновление прошивки → Записать новый образ
```

## 16. Что делать при проблемах

### LuCI не открывается, но роутер загружается

1. Подключитесь кабелем к LAN.
2. Отключите VPN и Wi‑Fi компьютера.
3. Проверьте адрес компьютера командой `ipconfig`.
4. Проверьте `ping 192.168.1.1`.
5. Попробуйте SSH:

```powershell
ssh root@192.168.1.1
```

### Ошибка после изменения сетевых настроек

Используйте failsafe OpenWrt. В этом режиме роутер обычно доступен по `192.168.1.1`, DHCP и Wi‑Fi отключены, поэтому компьютеру задают статический адрес, например `192.168.1.10/24`.

### Сброс OpenWrt

Сброс удаляет настройки и установленные пакеты, но **не возвращает заводскую прошивку Xiaomi**.

Через SSH:

```sh
firstboot -y && reboot
```

Используйте это только если действительно готовы потерять конфигурацию OpenWrt.

### Роутер не загружается

Не выполняйте наугад `nand erase`, `mtd write`, `ubiformat` и команды изменения загрузчика. Полное восстановление может потребовать UART/TFTP и исходные файлы из папки `backups`. Это уже процедура для опытного пользователя.

Если роутер не отвечает:

1. Не удаляйте резервную копию XMiR.
2. Запишите поведение и цвет индикатора.
3. Проверьте DHCP и адреса `192.168.1.1`/`192.168.31.1` по кабелю.
4. Обратитесь к инструкции восстановления именно для RD23/MT7981.

## Краткий контрольный список

Перед записью первой прошивки должны быть выполнены все пункты:

- [ ] На наклейке указано RD23.
- [ ] XMiR определяет MediaTek AX3000T, а не RD03v2/Qualcomm.
- [ ] Используется Ethernet, VPN и Wi‑Fi компьютера отключены.
- [ ] PPPoE-данные сохранены.
- [ ] Полная резервная копия XMiR создана и скопирована в два места.
- [ ] SHA-256 обоих образов совпадает.
- [ ] В папке XMiR `firmware` лежит только обычный `initramfs-factory.ubi`.
- [ ] Файлы `ubootmod` не используются.
- [ ] Питание стабильно.
